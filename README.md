# Self Inquiry

用心理学理解自己。这里记录我反复遇到的问题、读到的资料、自己的观察和尝试。

## 七个主题

| # | 主题 | 核心问题 |
|---|------|----------|
| 1 | [安全感与不确定性](topics/01-安全感与不确定性.md) | 为什么我如此在意事情是否符合预期？如何在无法预测和控制结果时保持安全感？ |
| 2 | [过度思考与信息搜集](topics/02-过度思考与信息搜集.md) | 为什么我总想提前研究所有细节？如何判断什么时候应该停止思考、开始行动？ |
| 3 | [秩序感与纠错冲动](topics/03-秩序感与纠错冲动.md) | 为什么我难以忍受错误、荒唐和不合理的事情？如何接受世界的不完美，而不总想介入和纠正？ |
| 4 | [空虚感与动力](topics/04-空虚感与动力.md) | 为什么没有事情需要处理时，我反而感到空虚？如何在不依赖目标、期待和持续进步的情况下获得充实感？ |
| 5 | [长期目标与人生方向](topics/05-长期目标与人生方向.md) | 为什么我需要长期投入的目标，却不愿预测遥远的未来？如何平衡长期方向与短期期待？ |
| 6 | [放弃与心理灵活性](topics/06-放弃与心理灵活性.md) | 如何判断什么值得坚持、什么应该放弃？如何减少对控制、效率和最优解的执着？ |
| 7 | [注意力与深度思考](topics/07-注意力与深度思考.md) | 在信息过载、社交媒体和 AI 时代，如何恢复注意力，减少对即时刺激的依赖，重新培养独立思考和长期专注的能力？ |

这七个问题互相关联：对确定性的需要（1）会推动过度准备（2）和纠错冲动（3）；没有“待处理的事”时的空虚（4）又和目标、方向（5）、能否放手（6）以及注意力被即时刺激占据（7）有关。写的时候可以互相链接。

## 怎么用

- **`topics/`**：每个主题一个文件，写具体情境、相关资料、自己的理解和小实验。理解变了就在「更新记录」里加一行，不删旧想法。
- **`journal/`**：随手记，文件名 `YYYY-MM-DD.md`。某个瞬间触发了某个主题，就先记在这里，之后再整理进对应主题。
- 让 agent 帮忙时，可以说「把今天这件事记到 journal，和主题 3 有关」或「帮我找主题 2 的资料并更新」。

> 这是自我探索的笔记，不是诊断。如果某种感受持续影响生活，找心理咨询师聊聊。
